# Operating Systems — Course Handout

**BMU CSE · Semester 3**
Sample material prepared for the EduAssist walkthrough. Upload it in **Library** with the type **Handout / syllabus** so the app extracts the course topics.

## Course structure

- Two lectures and one lab per week.
- Labs use Linux and a small C scheduling simulator.
- One mid-semester test and one end-semester exam, as announced in class.
- Tutorials cover numerical problems: scheduling traces, page-fault traces and banker's-algorithm tables.

## Course topics

1. **Operating systems and the kernel**
2. **Processes, the PCB and context switches**
3. **Threads and CPU scheduling**
4. **Virtual memory and page faults**
5. **Thrashing and the working set**
6. **Deadlock: conditions, avoidance and recovery**

## Reading

Silberschatz, Galvin and Gagne, *Operating System Concepts* — process management, CPU scheduling, deadlocks and virtual memory.
